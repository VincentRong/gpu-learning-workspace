# Recommended Resources

Use these as the default reading list. Prefer finishing the local weekly note
before opening more tabs.

## Official references

- NVIDIA CUDA Programming Guide
- NVIDIA CUDA Best Practices Guide
- NVIDIA CUDA on WSL User Guide
- NVIDIA Nsight Compute documentation
- Triton tutorials
- PyTorch custom C++ and CUDA operator tutorial

## Books

- `Programming Massively Parallel Processors`
- `CUDA by Example`

## How to use the resources

- Weeks 1-3: focus on setup docs, execution model, and beginner CUDA examples
- Weeks 4-6: read profiling and best-practice sections when a kernel becomes slow
- Weeks 7-10: use the LLM hotspot note to frame what you see in Triton or PyTorch
- Weeks 11-12: re-read your own notes and benchmark results before reading more

## Reading discipline

- One primary source at a time
- Turn every reading session into one short written takeaway
- If a source does not help you explain a benchmark, park it for later
