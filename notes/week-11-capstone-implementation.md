# Week 11: Capstone Implementation

## Goal

Turn one lab family into a focused mini project.

## Theory block

- Re-read your chosen capstone note
- Define your benchmark matrix before touching code

## Hands-on block

- Implement the capstone end to end
- Keep outputs and benchmark logs
- Write down one performance hypothesis before each change

## Deliverables

- Runnable code
- Benchmark table
- Draft summary of bottlenecks and optimizations

## Exit criteria

Your project runs repeatably and has at least one honest baseline comparison.
